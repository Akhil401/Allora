# App icons

Replace these with real PNGs before deploying the PWA:

- `icon-192.png` — 192×192, used for the home-screen icon.
- `icon-512.png` — 512×512, used for splash + maskable icon.

Until real icons are added, Android will fall back to a generated icon. Any
image generator or a tool like https://realfavicongenerator.net works.
